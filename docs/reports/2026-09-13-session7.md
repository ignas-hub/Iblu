# Session 7 — the reconstructed day

Run 2026-09-13 evening against `docs/plans/2026-09-13-sessions5-8.md` §3.

## What exists now that did not

`blocks` itself was built earlier the same day (`0406f36`), so this session was
the half the brief cared most about: making the day *cover itself*, and making
the week readable in minutes.

**An unaccounted stretch is now a block, not a hole (2026-09-13).** Any span of
at least 30 minutes between 07:00 and 20:00 Zagreb that neither evidence nor the
calendar accounts for becomes an `untracked` block — `venture=NULL`,
`ambiguous`, no evidence. The earlier version emitted nothing there, reasoning
that inventing a block invents a fact. Both readings honour "silence is never
presence"; only this one gives Ignas something to answer. Verified on a real
day: 11 blocks, full coverage, zero overlaps, none under 15 minutes.

**A tap is truth; a reconstruction is a guess.** Blocks with
`confidence='fact'` are held out of a rebuild entirely and the new timeline is
cut around them. Re-running the analyst supersedes only what it inferred.

**An LLM judges the day it did not build.** `analyst/judge.py` may correct a
block's venture, work type, project and reasoning. It may not move a boundary
(a model that can reshape the timeline can invent an hour of work), may not
upgrade confidence (only a tap makes a fact), may not invent a venture, work
type or project, and may not fill in an untracked stretch. Every one of those is
checked *after* the call rather than asked for in the prompt, and any violation,
timeout or malformed response is a silent no-op that records `llm=false`. On
real data it produced work types the deterministic pass could not — "Forwarded
receipts and travel confirmations — evidence is admin, not blt".

The duration stays IBLU's: the judge writes only the "why" and the `N min ·`
prefix is prepended afterwards. Letting it rewrite the whole line lost the
minutes, which is the one number a glance at a card needs.

**The week reads in minutes.** `review()` now returns minutes per venture, work
type, attention and confidence, plus the untracked and displaced shares — all
from the reconstructed day, all split `fact` / `inferred`, because a minute
Ignas confirmed and a minute IBLU guessed are different evidence and must never
be added together silently. It returns `None` until a day has been
reconstructed, so a caller falls back to counts rather than printing a confident
zero.

This replaced a number that was true and useless. "Untracked: 0% of the
window's days had no signal at all" became "**Untracked: 77% of the
reconstructed week is unaccounted for — unknown, not idle**". That is the
uncomfortable number the mission asks for.

**The Secretary calendar shows the day**, one calendar covering every venture,
colour-coded by attention, transparent so a record of the past never makes him
look busy, and with notifications off so it never buzzes about yesterday. The
intent calendar is never written to. Ambiguous blocks are named after the event
they failed to account for — "? Womanizer alignment" says something;
"unattributed" says nothing.

  (`129b3fa`), so §3.4's "create it via the API" was a no-op.
- **`evidence` is a JSON array of signal ids**, not the brief's
  `{"signal_ids": […], "rule": …, "llm": …}` object. The rule and the LLM flag
  live on the run, not on each block.
